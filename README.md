## How to Run the Program

I use yarn as the package manager, so we can use both commands (`npm` and `yarn`) to configure the application. Here are the steps:

1. Install the dependencies by running the following command.
   - npm:
     ```
     npm install
     ```
   - yarn:
     ```
     yarn
     ```
2. Build the application by running the following command.
   - npm:
     ```
     npm run build
     ```
   - yarn:
     ```
     yarn build
     ```
3. Start the application by running the following command.
   - npm:
     ```
     npm start
     ```
   - yarn:
     ```
     yarn start
     ```
